# 🩺 医疗 QA 数据集 <think> 标签提纯与净化决策网格 (Think Tag Purification & Routing Decision Grid)

在医疗垂直领域大模型进行监督微调（SFT）与强化学习（RL，如 R1 类推理模型）的数据准备阶段，思维链（`<think>` 块）的质量直接决定了模型最终是否具备**深层临床决策（Reasoning CDSS）**与**防范幻觉**的能力。

为了指导数据集的清洗工程，本网格制定了 `<think>` 标签的 **“Keep（保留并提纯） vs. Strip（彻底剥离）”** 黄金分割判定标准，并对本数据集的前 24 条典型切面/临床问题进行了系统化归类与分流决策。

---

## ⚖️ 思维链净化分流：黄金判定法则

在进行大批量数据清洗时，算法与数据工程师必须遵循以下底层判定逻辑，严禁“一刀切”式地全部保留或全部剔除。

### 🟢 保留并提纯 (Keep & Optimize <think>) —— 价值评级：⭐⭐⭐⭐⭐
满足以下条件之一的思维链，必须予以保留，并过滤掉其中的工程噪声，提纯为高含金量的 CoT 语料：
1.  **因果演绎链条 (Causal Chain)**：思考中清晰展示了从 `A (前置状态) -> B (药理/代谢介导) -> C (生理功能改变) -> D (临床恶化/危象后果)` 的严密机制链。
2.  **微观药理与宏观病理映射 (Micro-Macro Mapping)**：例如将中成药的多靶点组分化学成分（如五味子素、原花青素），与疾病底层的细胞因子、炎症浸润或微循环通路进行机制层面的映射。
3.  **临床鉴别诊断与排查逻辑 (Differential Diagnosis & Clinical Screening)**：针对症状相似但机制对立的毒性反应（如巴比妥类中毒 vs. 阿片类中毒），思考中展现了鉴别、排除及安全风险分级逻辑。

### 🔴 彻底剥离 (Strip <think> Directly) —— 价值评级：⭐
凡是符合以下特征之一的思维链，在微调训练时必须彻底将 `<think>` 标签及其内部文字删除，将其退化为常规的“Alpaca-Instruct”直答数据对，避免模型产生“唯唯诺诺的废话文学”或格式幻觉：
1.  **常识性陈述与万能免责声明 (Trivial Facts & Hedging)**：仅包含如“在医生指导下用药”、“注意遵循用法用量”、“多喝水多休息”等放之四海而皆准的套话。
2.  **纯粹的事实罗列与说明书复读 (Data Rote Learning)**：仅把正文中即将输出的内容换个句式在 `<think>` 内部复读一遍，缺乏任何思维拆解。
3.  **工程与 RAG 占位噪声 (Engineering Schema Noise)**：在思考链中罗列大量的 JSON 输出模版、RAG 检索片段名字（如 `《说明书第几页》` ）、以及引导词（如 `回答应强调...` ）。

## 🚀 企业级微调（SFT / RL）应用指南

在您的后续 pipeline 或者大批量数据清洗工作中，本决策网格可以直接作为大模型自动分流清洗的 **金标准 Prompts 判定逻辑**。

1.  **自动分流路由（Routing Pipeline）**：
    编写 Python 数据清洗脚本，对于属于 `Strip` 决策的切面（如用法用量、说明书直录等），直接使用正则或 JSON 解析，**将其 `<think>` 标签和内部数据彻底过滤**，包装为常规的问答对。
2.  **纯化提取（Purification Pipeline）**：
    对于属于 `Keep` 决策的切面，通过 `llm_purify_dataset.py` 调用大模型，把类似 `“我们要根据 refs...”` 这种元指令和 JSON Schema 工程占位模板完全拔除，**只保留上述表格中“绿色（Keep）”部分对应的高保真机制推导**。
3.  **强化学习（RL）微调输入**：
    将提纯后的高质量 CoT 数据作为 RL 训练 of Baseline，引导模型生成更具逻辑严密性、更懂机制鉴别的临床深度思考。
